# 计算机专业基础——数据结构和算法

---
## 目录结构

每个文件夹代表了一个**算法**或**数据结构的所有操作**。

## 代码结构

尽量用**单个源文件**完成全部的数据结构的定义和算法的实现，适配408算法和算法竞赛对单源文件的要求。源文件开头需注释输入输出。**无需使用栈、队列**的算法使用C来实现，否则使用C++实现。

代码开头：
```
/*
 * File: .c
 * Purpose:
 * Input:
 * Output:
 */
```

## 评价

使用deepseek纠正一些编程上的不足。

提示词
```
<代码>
用中文批评我的代码。
然后依据我的原有代码，以英文完善该代码的头部注释，
你无需添加除了Purpose, Input, Output以外的其他注释。
```

最后以一个markdown文件总结经验，不足之处。

## 快速运行
进入到项目根目录后，执行：

```
make
```
即可编译每个目录内的源文件得到可执行文件存放在各个目录

## 图的遍历测试示例
以下两个示例可用于测试所有图结构的遍历算法。
编程实现有向图，即可调用两次建立弧的函数建立无向图。
弧的输入默认为有向图
### 示例一
结点：0-6
弧的数量：8
弧：0 1 1 3 1 4 3 0 3 2 3 5 4 6 6 5

预期输出(若为邻接矩阵，则输出序列唯一，否则不唯一，下同)
```
BFS: 0 1 3 4 2 5 6
DFS: 0 1 3 2 5 4 6
```

### 示例二
结点：0-6
弧的数量：10
弧：0 1 0 2 1 3 1 4 3 0 3 2 3 5 4 3 4 6 6 5

预期输出
```
BFS: 0 1 2 3 4 5 6
DFS: 0 1 3 2 5 4 6
```

## 图的最短路径算法测试示例
### 无权图(bfs_min_distance)
结点：0-6
弧的数量：10
弧：0 1 0 2 1 3 1 4 3 0 3 2 3 5 4 3 4 6 6 5

预期输出
```
distance:0 1 1 2 2 3 3 
path:-1 0 0 1 1 3 4 
```

### 带权图(dijkstra、floyd)  
结点：0-8
弧的数量：15
弧信息：0 1 3 0 5 2 0 6 6 0 7 6 1 2 1 1 6 2 2 3 4 2 6 4 3 4 1 3 6 2 3 7 5 4 5 1 4 7 3 5 7 3 6 7 3

预期输出
```
distance:0 3 4 8 9 2 5 5 
path:-1 0 1 2 3 0 1 5
```
