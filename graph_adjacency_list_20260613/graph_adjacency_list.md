## 编程经验总结

### 结构体链式引用
对于链式结构体引用，如`g->vertex_list[v1].first_arc->adjacent_vertex`  
1.g后面用`.`还是`->`取决于g本身是结构体还是结构体指针，因g是结构体指针，故用`->`
2.vertex_list[v1]后面用`.`是因为vertex_list[v1]是结构体
3.first_arc后面用`->`是因为其是结构体指针

### 为内存变量赋值

1.
```
内存变量 = 值
```

2.
```
*指向该内存变量的指针 = 值
```

3.
```
指向该内存变量所在结构体的指针->该内存变量 = 值
```
