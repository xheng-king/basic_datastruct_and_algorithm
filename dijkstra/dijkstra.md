## 反思

dijkstra的final数组功能与广搜bfs、深搜dfs的visit数组一致。

### 整体实现：
1.标记源节点的final为1，distance为0，path为-1
2.设置一游动结点，初始为源节点，进入VERTEX_NUM-1轮循环，每次循环得到一个结点最终的distance和path
　　2.1内层循环遍历循环游动结点的所有邻接结点，若邻接结点final为0，且其distance超过了目前游离结点的distance与游离结点到其的距离之和，则更新该邻接结点的distance与path。
　　2.2访问完游离结点的所有邻接后，再利用一个内层循环遍历**所有final为0的结点**，选择的结点中distance最小的结点，将游离结点置为该结点，并将其final置1。


## 错误
### 1
2.2步的第二个内层循环，很容易将遍历**所有final为0的结点**写成遍历**当前游离结点的邻接结点中final为0的结点**。这就造成了错误。**dijkstra算法并不是在一个图结构中一条道走到黑，而是可以跳跃的**。一定是遍历所有结点而非仅仅当前游离结点的邻接结点。
### 2
```
int dist[VERTEX_NUM] = {__INT_MAX__/3};
int path[VERTEX_NUM] = {-1};
```

上述不为0的初始化仅仅只将首元素置为设置值，导致其余都为0；
